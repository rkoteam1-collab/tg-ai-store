# AIshopify Chat: текущий статус и запуск

Отдельный бот: `@AIshopifyGPT_bot`. Пакет: **1 000 000 токенов суммарно** для ChatGPT, Claude и Gemini; входящие, исходящие и повторно отправленная история учитываются по данным провайдера. Это не по миллиону на каждого. Пока поддерживается текстовый чат. Генерации изображений и загрузки файлов ещё нет.

**Продажа выключена.** На сайте нет активной кнопки оплаты пакета и нет маршрута, выпускающего код по запросу клиента. Текущий СБП-каталог магазина не содержит этот пакет. Цена не установлена. До отдельного решения о платёжном сценарии нельзя обещать выдачу кода после QR-платежа. Существующие товары магазина и их оплата остаются прежними.

## Временный запуск без Render

`node server/chat/local-demo.js` запускает отдельного бота через Telegram polling на том компьютере, где выполняется команда. Ему нужны `CHAT_BOT_TOKEN` и `ADMIN_ID` в переменных окружения. Публичный сайт и webhook для этого не нужны. Этот режим допускает только владельца, использует тестовые ответы и временную память: коды, баланс и переписка исчезнут после остановки процесса. Покупки и настоящие API в нём отключены. Для круглосуточной работы компьютер должен оставаться включённым; полноценному запуску нужна постоянная база.

## Тест бота

Для запуска тестового режима нужны переменные среды сервера:

| Переменная | Значение |
| --- | --- |
| `CHAT_BOT_TOKEN` | Токен **отдельного** бота из BotFather. Не вставлять в клиентский код и переписку. |
| `CHAT_DATABASE_URL` | Строка подключения к постоянной PostgreSQL. Файлы Render Free для токенов и кодов не подходят. |
| `CHAT_CODE_SECRET` | Случайная постоянная строка не короче 32 символов. Не менять после выдачи кодов. |
| `CHAT_DEMO_MODE` | `true` для тестовых ответов без обращений к поставщикам. |
| `ADMIN_ID` | Telegram ID владельца; только ему доступны тестовый бот и команда `/demo`. |
| `BACKEND_URL` | Публичный HTTPS-адрес сервера для webhook. Если не задан, используется `WEBAPP_URL`. |

После запуска владелец открывает `@AIshopifyGPT_bot`, вводит `/demo`, получает одноразовый тестовый код и отправляет его боту. Постоянные кнопки **«Сменить модель»**, **«Остаток токенов»** и **«Чат / изображения»** открывают выбор модели, показывают общий баланс и переключают меню режимов. В режиме изображений до подключения API бот сообщает, что генераторы недоступны; токены не списываются. Команда `/balance` тоже показывает остаток; `/new` очищает историю текущей модели; `/last` повторно показывает последний оплаченный ответ без нового списания. `/menu` восстанавливает клавиатуру. Тестовый код привязан к Telegram ID владельца. Демо-ответы списывают условные токены для проверки учёта и не используют реальные API.

## Подключение настоящих моделей

На сервере, кроме постоянной базы, задаются `OPENAI_API_KEY` и `OPENAI_MODEL`, `ANTHROPIC_API_KEY` и `ANTHROPIC_MODEL`, `GEMINI_API_KEY` и `GEMINI_MODEL`. Для ключа Anthropic без привязки к рабочей области может потребоваться `ANTHROPIC_WORKSPACE_ID`. Конкретные модели выбираются после получения доступа и проверки условий провайдеров. `CHAT_DEMO_MODE=false` выключает тестовые ответы. Ключи никогда не передаются браузеру.

Перед продажами нужны согласованная цена, платёжная интеграция и проверка фактического статуса платежа на сервере. Код должен выпускаться только для заказа со статусом «оплачен», подтверждённым самим провайдером платежа, с защитой от повторной выдачи. Сейчас метод `issuePaidVoucher` подготовлен для такого обработчика, но ни один публичный маршрут его не вызывает. Без базы, ключей и этого обработчика покупка не заработает, даже если запустить отдельный бот.

Для цифрового пакета внутри Telegram следует отдельно сверить выбранный способ оплаты с [правилами Telegram](https://core.telegram.org/bots/payments-stars). До этого момента QR-оплата пакета в Mini App и боте не включается.
